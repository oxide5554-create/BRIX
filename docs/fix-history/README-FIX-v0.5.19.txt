 1. 📦 ГЛАВНЫЙ ФИКС — ЯЩИК НЕВИДИМ, ПАРАШЮТ ОСТАЁТСЯ.
    Настоящий корень нашёлся в ЗАГРУЗЧИКЕ МОДЕЛЕЙ js/game/glb.js:
    скелет биндился с НУЛЕВОЙ (identity) матрицей — «bind = identity»,
    а настоящий GLTFLoader биндит с мировой матрицей меша. У моделей,
    где скин-меш сидит под нодой с трансформом (ящик аирдропа — под
    _rootJoint), вершины УЕЗЖАЛИ: v0.5.17 «невидимый ящик», v0.5.18
    «парашют есть, ящика нет». Теперь bind(skeleton, mesh.matrixWorld)
    — как в GLTFLoader. Для моделей с identity-цепочкой (игрок,
    шприц) ничего не меняется — там matrixWorld и был identity.
    Дополнительно: каждый ящик грузит СВОЮ свежую копию модели
    (BrixGLB.parse заново — свои кости и свой скелет). Клоны
    Object3D.clone() скелетную модель рвут всегда — больше не
    используем их для ящика. Файл 180 КБ локальный, ящиков мало.
    ПРОВЕРЕНО СКРИНШОТОМ: ящик стоит перед камерой — табличка,
    коробка, кольцо. Если файл модели вдруг не доехал — будет серый
    куб-заглушка: ящик ВСЁ РАВНО видно и можно открыть.

 2. 🪂 ПАДЕНИЕ С НЕБА. Самолёт всегда сбрасывал груз, ПРОЛЕТАЯ НАД
    ТОЧКОЙ: сервер ждёт, пока самолёт дойдёт до точки по курсу
    (лог «[air] сброшен adN»), и отдаёт ящик с высоты самолёта
    минус 3 м (85–145 м). Ящик падает с парашютом ~9 м/с, качается,
    при посадке парашют КРАСИВО ТАЕТ, под ящиком золотое кольцо.
    Раньше этого не было видно ТОЛЬКО потому, что сам ящик не
    рендерился (см. п.1) — летал «пустой» парашют. Теперь падение
    видно целиком. Перезаход во время падения: ящик продолжит
    падать с той же высоты («восстановлено ящиков из сейва…
    падают: N»).

 3. 🎁 ЛУТ v0.5.19 — «И ХОРОШИЙ, И ПЛОХОЙ», БЕЗ СЕРЫ (просьба):
    • база всегда: scrap 6–16, metal 4–10, порох 5–14, патроны 4–12;
    • СЕРЫ БОЛЬШЕ НЕТ ВОВСЕ (проверено: 0 из 200 розыгрышей);
    • РОЗЫГРЫШ 50/50: «повезёт» — военная часть (корпус АК 60%,
      С4 40%, шприц 50%, берданка 30%), «не повезёт» — скромный
      добор (труба 50%, пружина 40%, берданка 15%);
    • СТВОЛ: максимум ОДИН (шанс 50%), обойма НЕ ПОЛНАЯ — 10
      патронов (томпсон 10, рев-карабин 2, дробовик 2);
    • револьвер 15%.
    В среднем ~6 видов лута на ящик — есть и жирное, и мелочь.
