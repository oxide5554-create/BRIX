# BRIX — бета-тест (чистые HTML + CSS + JS)

Браузерная игра в стиле Rust: выживание на процедурной карте + ПвП-арена,
мультиплеер на самописном Node.js-сервере (WebSocket без npm). Сборка
**v0.5.24** (клиент `0.4.68`, сервер `0.5.24`).

### Что нового в v0.5.24 (по заявкам игрока)
- **КАРТА BRIXLAND УДАЛЕНА** — осталось ДВА сервера: «Генерация»
  (процедурная карта, порт 8789) и BrixPvP (арена, порт 8788).
- **ПРОЦЕДУРНАЯ КАРТА — АРХИПЕЛАГ**: 4-6 островов с горами вместо
  одного круглого острова; у каждой карты СВОИ число/размер/разброс
  островов, высота гор, амплитуда холмов. Всё вне островов — вода:
  пустых мест нет. Край мира квадратный, карта на **M** открывается
  **НА ВЕСЬ ЭКРАН** (морской фон, компас, штамп BRIX).
- **САМОЛЁТ ЛЕТАЕТ НА «ГЕНЕРАЦИИ»**: аирдропы больше не «только
  BrixLand». В ПЕРВОМ ящике гарантированная **C4**, а в чат пишется
  «SERVER: АИРДРОП ВЫЛЕТЕЛ С C4 — ПОЗИЦИЯ: …».
- **ВАЙП С ОТСЧЁТОМ**: за 60 секунд сервер сам пишет в чат
  «SERVER: WIPE SERVER 60…1», затем КИКАЕТ всех, вайпит мир и делает
  10-секундный тех. перерыв — карта генерируется у всех заново.
  У админов есть КНОПКА «ВАЙП СЕРВЕРА» (тот же отсчёт 60 с).
- **ФИКС БОЧЕК НА «ГЕНЕРАЦИИ»**: после вайпа сервер искал бочку в
  устаревшем индексе — «сервер не принял удар» и дроп по старым
  координатам. Теперь поиск по текущему миру: удар всегда засчитан,
  лут падает под бочку.
- **ФИКС ОПЫТА/НАГРАД**: смерть больше не стирает опыт и уровень;
  прогресс (lvl/xp/claimedLevels) сохраняется в браузере и на сервере —
  после перезахода награда за 1-й уровень не «оживает» снова.
- **ПОЛКА НАГРАД ПЕРЕРИСОВАНА** в стиль игры (тёмный металл, ржаво-
  красный акцент, стенсил-заголовки) вместо золотистой «HTML-полки».
- **ФИКС ЛЕТАЮЩИХ ДЕРЕВЬЕВ**: деревья/ящики лагеря ставятся по сетке
  рендера (meshHeightAt) с посадкой в землю — как руда.
- **АДМИНУ «НА СПАВН»**: кнопка мгновенного респавна на плато (0:0) —
  выручает, если «не заспавнился». Загрузка мира больше не замирает
  в фоновой вкладке (гонка rAF/таймер).

## Запуск

Нужен **Node.js** (https://nodejs.org). Батники в корне:

| Батник | Что делает | Порт |
|---|---|---|
| **START-ALL.bat** | ВСЁ сразу: меню + 2 игровых сервера | — |
| START-GAME.bat | меню + «Генерация» (быстрый старт) | 8780 + 8789 |
| START-MENU.bat | только меню (интерфейс) | 8780 |
| START-PVP.bat | BrixPvP — арена «Полигон» | 8788 |
| START-WIPE.bat | «Генерация» — вайп-мир (карта раз в сутки) | 8789 |
| CLEAR-BUILDS.bat | стереть все постройки (с бэкапом) | — |
| rust/BUILD-UTILS.bat | собрать утилиты brix-ping / brix-info | — |

Играть: открой **http://localhost:8780** (меню) → вкладка СЕРВЕРА.
Одному игроку можно просто открыть `index.html` двойным кликом.

### Dev Tunnels (игра с друзьями через интернет)

Пробрось порты **8780, 8788, 8789**. Адреса вида
`https://<id>-8789.euw.devtunnels.ms` распознаются автоматически:
меню открывается на `-8780`, а игра сама ходит на `-8788/-8789`.
Никаких правок кода не нужно.

## Серверы

| Реалм | Порт | Что внутри |
|---|---|---|
| `menu` | 8780 | только интерфейс (меню отделено от сервера) |
| `brixpvp` | 8788 | арена «Полигон» (СЕКТОР-9): боты, команды, бесконечные патроны |
| `brixwipe` | 8789 | выживание на **процедурной карте-архипелаге** (4-6 островов по сиду): вайп раз в сутки с **отсчётом в чате** и киком всех (`data/brixwipe/wipe.json`), аирдропы с C4, пустыня/арктика/кактусы |

**Вайп (v0.5.24):** за 60 с сервер пишет в чат «SERVER: WIPE SERVER N»,
в 0 — кикает всех (`wipekick`), стирает мир, берёт новый сид, 10 с
держит тех. перерыв (вход закрыт) — потом карта генерируется заново.
Админ запускает то же кнопкой **«ВАЙП СЕРВЕРА»** в панели (клавиша 9).

У каждого реалма СВОИ сохранения `data/<realm>/` — свой мир, свои игроки
и **свой инвентарь** (вещи не переезжают между серверами). `admins.json`
и `bans.json` — общие.

## Уровни и награды

- У всех игроков: **0 часов, 1 уровень**. Максимум — **250**.
- Опыт дают ресурсы **после полного ломания**: дерево **25**, камень **30**,
  железо **15**, сера **15**. На сервере опыт считается **авторитетно**
  (в players.json каждого реалма), накрутить нельзя.
- До следующего уровня: `300 × n` опыта (до 2-го — 300, до 3-го — 600…).
- **Наградная полка — В ГЛАВНОМ МЕНЮ** (пункт «НАГРАДЫ», с золотым
  счётчиком незабранных наград): линия прогресса до следующего уровня
  + **монеты за каждый уровень** (кнопка ЗАБРАТЬ). В игре при добыче —
  только тост «+N опыта — источник».

## Чат

- **Enter** (или T) — открыть строку ввода; Enter — отправить, Esc — закрыть.
- На телефоне — кнопка **ЧАТ** в блоке тач-кнопок.
- На сервере антиспам 0.4 с; сообщения видят все.

## Мобильное управление

- Хотбар: **тап — выбрать слот, второй тап по тому же слоту — ИСПОЛЬЗОВАТЬ**
  (тыква съедается, шприц колется).
- Джойстик, кнопки УДАР/ПРИЦ/ПРЫЖ/БЕГ/F/КРАФТ/СУМКА/СТРОЙ/R/СИД/ЧАТ.

## Оружие и инструменты (в руках)

- Револьвер и дробовик **крупнее** и чуть дальше от хотбара; **прицел (ПКМ)
  по центру экрана**.
- Инструменты (топоры/кирки/факел/булава) держатся **под углом**, размер
  увеличен.

## Оптимизация пинга

- `/ping` — мгновенный эндпоинт на каждом сервере; HTTP-сокеты TCP_NODELAY.
- Утилита **brix-ping** (Rust, без зависимостей) меряет задержку тремя
  способами: `tcp`, `http`, `ws` (как пингует сама игра):

```
rust\brix-utils\target\release\brix-ping ws localhost:8789 20
rust\brix-utils\target\release\brix-ping ws lpxm82mp-8789.euw.devtunnels.ms 20
rust\brix-utils\target\release\brix-info localhost
```

Сборка под Windows: `rust/BUILD-UTILS.bat` (нужен Rust — https://rustup.rs).

Как читать: локальный `ws` мал, а через туннел большой → задержку добавляет
сам туннел (Dev Tunnels гоняет трафик через Европу — это инфраструктура,
не код игры). `tcp` мал, а `ws` велик → смотри обработку на сервере.

## Встраивание моделей (устойчивость к 404)

Тыква и тыквенная лоза **встроены в код** (js/game/embeddata.js —
`scripts/gen_embed_add.py`): если файлов нет на сервере, «серых кубов»
не будет — модель возьмётся из `BrixEmbed.models`. Кactus HD (9.7 МБ)
не встраивается — лежит в `assets/models/cactus_saguaro.glb` (нужен
только на BrixWipe).

## Проверка серверов

```
http://localhost:8780/status   — меню (menu: 1)
http://localhost:8789/status   — Генерация (seed, wipeIn)
http://localhost:8788/status   — арена
http://localhost:8789/ping     — мгновенный pong
```

## Проверки (без браузера)

```
node scripts/verify-isolation.js      — изоляция серверов: инвентарь, лут,
                                        дома, чекблоки, лозы, порты (28 проверок)
node scripts/check-terrain-sync.js    — рельеф сервер/клиент идентичен
                                        (гарантия, что лозы/тыквы совпадут)
```
Обе проверки должны печатать «ВСЁ ЗЕЛЁНОЕ» / «OK».

## Анти-кэш

`index.html` шлёт `no-store`, скрипты версионируются `?v=NNN`, patch.js
докачивает изменившиеся файлы по `/manifest.json`. Если после обновления
ничего не поменялось — Ctrl+Shift+R.
