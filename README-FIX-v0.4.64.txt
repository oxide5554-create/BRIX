BRIX v0.4.64 — ДВА СЕРВЕРА: BrixLand + ПВП-арена «Пепел»
============================================================

ЧТО НОВОГО
1) ВКЛАДКА «СЕРВЕРА» — СПИСОК СЕРВЕРОВ (полностью переделана)
   • Два официальных сервера карточками:
       BRIX • BrixLand  — ВЫЖИВАНИЕ (порт 8787)
       BRIX • BrixPvP   — ПВП АРЕНА «Пепел» (порт 8788)
   • У КАЖДОГО свой живой счётчик онлайна и свой состав игроков
     (опрос /status каждые 4 с);
   • карточки «СЛУЖЕБНЫЙ СЕРВЕР» и «Последний сервер» УБРАНЫ,
     надписи ADMIN в вкладке больше нет (заголовок — «СЕРВЕРА»).

2) ДВА РЕАЛМА — СВОИ СОХРАНЕНИЯ И ИГРОКИ
   • server.js запускается переменными окружения:
       node server.js                                    → BrixLand  (8787)
       BRIX_REALM=brixpvp BRIX_PORT=8788 node server.js  → BrixPvP   (8788)
   • у каждого своя папка: data/brixland/ и data/brixpvp/
     (world-objs.json, world-epoch.json, players.json, social.json);
   • файлы BrixLand при первом запуске переезжают в data/brixland/
     АВТОМАТИЧЕСКИ — мир и сохранения не теряются;
   • admins.json и bans.json ОБЩИЕ (админ/бан на оба сервера);
   • START-MULTIPLAYER.bat поднимает ОБА сервера.

3) ПВП-АРЕНА «ПЕПЕЛ» (BrixPvP)
   • СВОЙ РЕЛЬЕФ: другой сид ландшафта (77701) — горы/долины/биомы
     не как в Brixland;
   • НЕ ЛЕС, А ЛОКАЦИЯ: ровная площадка ~78 м у центра без деревьев,
     два кольца валунов-укрытий + 4 каменные «стены», лес вокруг
     прорежен вдвое (150 вместо 340 деревьев); спавн — центр арены;
   • СВОЙ лут: раскладка чекблоков другим сидом (77702);
   • БЕЗ ХОТБАРА/КРАФТА: хотбар скрыт, Q молчит, инвентаря нет;
   • E — СПИСОК ВСЕГО ОРУЖИЯ: булава, револьвер, револьвер-карабин
     3×, дробовик, калаш, томпсон, С4 (инструментов нет). Клик —
     оружие в руках;
   • ПАТРОНЫ БЕСКОНЕЧНЫЕ: перезарядка заправляет обойму и НЕ тратит
     запас (время перезарядки прежнее, на бегу стрелять нельзя).

4) МАГАЗИН СКИНОВ — ТОЛЬКО ДЛЯ АДМИНОВ
   • вкладка СКИНЫ скрыта у обычных игроков;
   • админ определяется по admins.json (через /status) или по
     adminon в игре.

ЗАМЕНИТЬ И ПЕРЕЗАПУСТИТЬ
  1) Скопировать поверх: server.js, index.html, папки js/ и css/,
     START-MULTIPLAYER.bat.
  2) Перезапустить ОБА сервера (START-MULTIPLAYER.bat).
  3) Мир/сохранения BrixLand переедут в data/brixland/ сами.

ФАЙЛЫ ВЕРСИИ
  server.js               — реалмы, data/<realm>/, /status+welcome, сиды
  js/data/servers.js      — список серверов (BrixLand + BrixPvP)
  js/ui/screens.js        — вкладка СЕРВЕРА: список с счётчиками
  js/social/social.js     — /status обоих серверов + isAdminAccount
  js/ui/sidebar.js        — СКИНЫ только для админов
  js/net/net.js           — порт подключения выбранного сервера
  js/game/gameworld.js    — ПВП-режим: сид рельефа, спавн арены,
                            бесконечные патроны, выдача патронов
  js/game/world.js        — арена: поиск площадки, расчистка леса,
                            кольца валунов-укрытий
  js/game/terrain.js      — смещение сидов (window.BRIX_TERRAIN_SEED)
  js/game/pvpweapons.js   — НОВЫЙ: список оружия на E
  js/game/inventory.js    — E на арене открывает список оружия
  js/game/craft.js        — Q на арене молчит
  js/game/minimenu.js     — имя текущего сервера в мини-меню
  js/core/i18n.js         — новые строки (СЕРВЕРА/ПВП, без ADMIN)
  js/core/icons.js        — иконки swords/trees
  css/menu.css            — стили арены и списка оружия
