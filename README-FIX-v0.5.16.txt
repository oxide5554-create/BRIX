 1) ПВП-АРЕНА: МЕШКИ-ЛУТБОКСЫ С ИГРОКОВ БОЛЬШЕ НЕ ПАДАЮТ

    умирающего игрока игнорируется — труп-лутбокс не создаётся.
    Старые трупы из сейва арены чистятся при старте сервера
    (в логе: '[corpse] арена: убраны старые трупы-лутбоксы: N').

 2) ФИКС «ТРУПЫ БОТОВ ЛЕЖАТ ПОСЛЕ РАУНДА»
    brixpvp-bots.js: при новом раунде сервер теперь шлёт
    'bspawn' тем ботам, которые лежали мёртвыми. Причина бага:
    spawnBot(b, true) в сбросе раунда НЕ рассылал 'bspawn', и
    клиентские регдоллы оставались лежать весь новый раунд.
    В логе: '[bots] новый раунд: счёт 0:0, боты на спавнах
    (встало трупов: N)'.

 3) ИГРОКИ ЗАХОДЯТ И ЗА ПЛАМЯ (не только за СТАЛЬ)
    • АВТОБАЛАНС при входе: игрок попадает в команду, где
      меньше живых людей; ничья → СТАЛЬ. Сам входящий исключён
      из подсчёта (pickTeam(p.id) — иначе первый игрок уезжал
      за ПЛАМЯ, засчитывая сам себя как синего).
    • Состав сторон остаётся 5 на 5: бот ЕГО команды уходит
      (синих ботов = 5 − синие игроки, красных = 5 − красные);
      вышел игрок — бот вернулся (reconcile по командам).
    • КИЛЛЫ: игрок приносит килл СВОЕЙ команде (handleBhit →
      teamOfPlayerBy; игрок убил игрока — новый вызов
      Bots.onPlayerKill в case 'phit'); бот убил игрока — в
      счёт команды бота (addKill(b.team)).
    • СВОИХ НЕ УБИВАЕМ: урон игрок-в-игрока на арене идёт
      только между РАЗНЫМИ командами; боты не трогают ни ботов,
      ни игроков своей команды (handleBhit по p.ateam).
    • КЛИЕНТ ВИДИТ КОМАНДУ: бейдж «ТЫ: СТАЛЬ (СИНИЕ)» /
      «ТЫ: ПЛАМЯ (КРАСНЫЕ)» под счётом команд (welcome.pvp.team,
      раньше бейдж был захардкожен СТАЛЬ); тост «ТЫ ИГРАЕШЬ
      ЗА: …» при первом стейте игрока (на welcome тост пропадал —
      фаза клиента ещё не 'playing'); лидерборд красит игроков
      по их команде (rows.t); команда едёт всем в 'join' (tm).
    • Анти-кэш: V 095 → 096 (index.html) — браузеры заберут
      новые pvphud.js / gameworld.js / servers.js.
