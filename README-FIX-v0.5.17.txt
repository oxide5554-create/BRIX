 ЧТО ЭТО: как в Rust — каждые 30 МИНУТ над островом пролетает
 самолёт и сбрасывает 1–3 АИРДРОПА в случайных местах СУШИ.
 Ящик падает на ПАРАШЮТЕ (9 м/с) и приземляется на первое,
 чего коснётся: земля/горы, ФУНДАМЕНТ, КРЫША (потолок) дома,
 насыпь чекблока. При посадке парашют КРАСИВО тает (поднимается,
 сжимается, растворяется). Лут «очень неплохой» — см. ниже.

 ✈ САМОЛЁТ (assets/models/plane.glb):
 • стартует ЗА КРАЕМ острова (~680 м), летит прямую через остров,
   из 14 случайных хорд сервер выбирает ту, где БОЛЬШЕ СУШИ
   вдоль пути (море = heightAt < 2.4) — путь над водой отсекается;
 • ВЫСОТА = максимальный рельеф вдоль пути + 42 м (не цепляет
   горы), скорость 26 м/с — полёт ПЛАВНЫЙ, без дёрганий;
 • сбросив груз, летит ДАЛЬЕ в ТОМ ЖЕ направлении и исчезает
   за краем карты ('planeGone');
 • ПАКЕТЫ: сервер НЕ пингует положение каждый кадр! Клиент сам
   докручивает полёт (скорость и курс постоянные). От сервера
   только: 'plane' (вылет), 'planeS' (якорь раз в 2 с — клиент
   мягко подтягивается), 'planeGone'. Звук двигателя
   (assets/sfx/airplane/Airdrop.wav, зациклен) громкость по
   дистанции до самолёта — слышно приближение.

 📦 ЯЩИК (assets/models/airdrop.glb, парашют встроен в модель):
 • ПАДАЕТ — виден всем, в т.ч. тем, кто ЗАШЁЛ ВО ВРЕМЯ падения
   (welcome присылает текущую высоту — докрутит сам);
 • ПРИЗЕМЛИЛСЯ — парашют тает, под ящиком золотое пульсирующее
   кольцо-маячок + плашка «✈ АИРДРОП»;
 • ЛУТ НА СЕРВЕРЕ (синхронный, как С4/трупы): scrap 15–30,
   metal 10–25, sulfur 10–25, ПОРОХ 20–50, ПАТРОНЫ 15–40,
   корпус АК 75%, стволы до 2 шт (калаш/томпсон/дробовик/
   револьвер-карабин/булава) С ОБОЙМАМИ, С4 35%, шприцы 65%,
   трубы/пружины/револьвер — шансами;
 • F у ящика (до 4.2 м) → лут-меню «АИРДРОП»: клик — забрать
   весь стек, стволы по одному с обоймой. Оптимистично у тебя,
   сервер — авторитет; у других остаток обновляется сразу;
 • ПУСТОЙ ящик исчезает ('adGone') — у всех сразу, меню закрывается;
 • ПЕРЕЗАПУСК СЕРВЕРА: ящики переживают (world-objs.json v8,
   adrops + adropSeq); упавшие лежат где лежали, ПАДАЮЩИЕ
   допадают после старта. Пустых из сейва не бывает.

 ⏱ ТАЙМЕР: автосброс каждые 30 минут (если на сервере есть
   хоть один игрок — без игроков самолёт не тратится).
 🛠 АДМИН-ПАНЕЛЬ: новая секция «СОБЫТИЯ СЕРВЕРА» — кнопка
   «✈ ПРИЗВАТЬ САМОЛЁТ С ГРУЗОМ» (op:'airdrop'). Ответ сервера
   придёт тостом/в панель.

 КАК ПРОВЕРИТЬ (1 минута):
    1. Замени файлы, перезапусти сервер.
    2. Админ-панель → «✈ ПРИЗВАТЬ САМОЛЁТ С ГРУЗОМ». В логе:
       '[air] самолёт вылетел: курс …°, высота … м, сбросов N (суша …%)'.
    3. Слышишь гул — самолёт над головой (громкость по дистанции).
    4. Через ~15–40 с ящики падают с парашютами; при касании
       парашют тает, кольцо мигает. В логе: '[air] ad1 приземлился
       (x, z) на H' — H это рельеф/крыша/фундамент.
    5. F у ящика → меню «АИРДРОП» → забирай. Опустел — исчез
       ('[air] ad… опустел — убран').
    6. Перезайди в игру — ящики (и ПАДАЮЩИЕ тоже) на месте.
    7. Перезапусти сервер — ящики всё ещё на месте.
